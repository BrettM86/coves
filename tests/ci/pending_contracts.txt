# Collections the AppView ingests that do NOT have a pipeline contract yet.
#
# docs/TEST_ARCHITECTURE.md §3.4a requires one ingestion contract per consumed
# collection: a record written straight to the PDS, indexed by the AppView's own
# consumers, observed on a serving endpoint. cmd/contract-manifest enforces it
# against internal/atproto/jetstream's consumer table, and this file is the
# phase-4 burn-down that keeps the check meaningful while the contracts are
# still being written — one domain per task, tasks 11-15.
#
# Format, one entry per line:
#
#   <collection>  # task <N>: why it is not contracted yet
#
# The task number is mandatory. A deferral nobody owns is how a burn-down
# becomes a permanent list, and this file has exactly one legal direction of
# travel: entries leave it. Adding a contract for a collection listed here makes
# the entry STALE and fails the check — delete the line in the same commit.
#
# Task 20 empties this file and flips cmd/contract-manifest to
# -allow-pending=false, after which "has a contract" is the only passing state.
